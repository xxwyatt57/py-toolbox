# python-utils

tiny python snippets i copy-paste between projects. not a package.

pin the snippets you like, edit them, forget attribution. that's the whole
point.

## contents

- `snippets/chunker.py`    — split an iterable into batches
- `snippets/urlencode.py`  — inline percent-encoding, no stdlib
- `snippets/csv_read.py`   — csv reader that guesses delimiters
